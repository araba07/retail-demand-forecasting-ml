# Data Source & Reference

The raw dataset used for this project is the **Online Retail II** dataset from the UCI Machine Learning Repository, hosted on Kaggle.

* **Data Source Link:** [Kaggle - Online Retail II UCI](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)
* **Dataset Scope:** 1,000,000+ transactional rows spanning B2B sales logs.
